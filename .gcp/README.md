# Google Cloud incident practice

Use the synthetic evidence in this directory for a tabletop interview. The exercise runs on paper or in a text editor.

## A reporting endpoint returns HTTP 429

Open the [scenario](cloud-run-capacity.json). Give the learner the brief and question first. Reveal each evidence item when they ask to inspect that source. Ask for a diagnosis, a mitigation and a recovery signal before discussing the worked response.

## Author another exercise

Copy the JSON shape into a file named for the new scenario ID. Give each observation a UTC time, source and unit where relevant. Pair service-level limits with saturation and request outcome evidence. Use fictional service names and synthetic observations.

Check the service behavior against the [Google Cloud documentation](https://docs.cloud.google.com/run/docs/troubleshooting).
