# Incident practice

Build a website where engineers can rehearse scenario-based interviews by investigating incidents on a guided canvas. Prioritize AWS, Kubernetes and DevOps scenarios, with a smaller selection for backend roles.

A useful first exercise gives the learner a symptom, a question worth asking and enough evidence to reason about the answer. For example, a Kubernetes scenario might open with rising latency after a rollout and ask which signal would distinguish an unhealthy pod from a slow dependency. Treat examples here as candidate content.

The current web and docs routes are starter pages. The planned library and canvas have yet to be implemented. Learner accounts and persistent progress are open design choices. Check the actual web route before describing a capability as shipped.
