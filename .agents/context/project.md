# Incident practice

Build a website where engineers can rehearse scenario-based interviews by investigating incidents on a guided canvas. The active catalog contains AWS incidents for DevOps and backend interview practice.

A useful first exercise gives the learner a symptom, a question worth asking and enough evidence to reason about the answer. The SQS exercise asks learners to distinguish a producer spike from a stalled consumer using queue age and Lambda event source mapping evidence.

The web app lists scenarios from the v1 API and opens a guided investigation with evidence, notes and an on-demand worked response. Learner accounts and persistent progress are open design choices. Check the actual web route before describing a capability as shipped.
